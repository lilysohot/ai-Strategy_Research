## 二、价格与能力基线

价格与基准（均为资料库转述，非一手发布页）：官方 API 定价为每百万输入 token 0.30 美元、每百万输出 token 1.20 美元，另有 50% 错峰折扣；权重以 MIT 许可证开放。DeepSeek 自报 11 项基准全部优于前代，其中 Terminal-Bench 4.0 从 31.2 升至 42.3，DeepSWE 从 74.2 升至 77.0，并称 11 项中 9 项胜过 GPT-5.6 Sol。这些数字不能与第三方同台比较：Google 发布页列 Astra 58.2、Opus 5.5 66.4，Artificial Analysis 独立测得 Astra 59%、Opus 5.5 60%，且截至 2026-10-19 AA 尚未测试 1017；9 月版 V4.1 Flash 的 AA 智能指数为 39，而领先开放权重模型在 44–46（MiMo-V2.6 Pro 46、GLM-5.3 45、Kimi K3 44）。价格战的另一端：第三方托管报价已低至每百万输入/输出 0.10/0.50 美元，低于 DeepSeek 官方费率；闭源入门级 Haiku 5.5 在 ≤100k token 提示下也是 0.10/0.50 美元，AA 单任务成本 0.21 美元，而 9 月版 V4.1 Flash 为 0.27 美元。架构侧，资料库（2026-09-22 报告，描述对象是 V4.1 Flash 而非 1017）记载 Prefill/Decode 每 token 仅激活约 8B/16B 参数，Global KV Cache 降至 V4Flash 的约 1/4、Persistent KV Cache 降至约 1/8，但未给出总参数量、上下文长度与训练成本。

**关于"1017 击败 GPT-6"这个流行说法**：资料库把它标为"一些文章声称"，并给出反驳——DeepSWE 77.0 与 Datacurve 榜 GPT-6 Astra 74.1 来自不同来源，Mercor 独立测试中四个模型均在 72 左右。**本答复不裁决谁更强**，因为不存在同 harness、同版本、同日期的可比数据。

## 三、影响机制：六条

### 1. 价格锚从"官方定价"移到"托管市场价格"
这次更新**官方没有降价**（0.30/1.20 维持不变）。真正的价格冲击来自 MIT 开放权重本身：第三方自托管后报出 0.10/0.50 美元，**低于 DeepSeek 自己的费率**。也就是说 DeepSeek 把价格决定权部分让渡给了托管市场——竞争手段从"官方降价"变成"开放权重"。同时闭源实验室在入门级产品同步降价（Haiku 5.5 短提示 0.10/0.50），**短提示场景下开源的价格优势已被挤压**。所以"DeepSeek 打价格战"要拆开看：不是它降价，而是它把降价的空间交给别人去做。

### 2. 技术叙事从"堆参数"转向"单位 GPU 产出"
资料库对 V4.1 Flash 一代的描述集中在架构与推理系统优化，而不是扩大规模：CED 把 40 层 Transformer 拆成 20 层 Encoder + 20 层 Decoder，让长 Prompt 不必走完后 20 层，降低 Prefill 计算量；CSA2 以 Full/Reindex/Reuse 三类层复用 Global KV 与 Top-K；叠加 FP4 Main KV 与 SWA Bounded Replay 后 Global KV Cache 降至约 1/4、Persistent 降至约 1/8；Single-Pass mHC 用 Kernel Fusion 减少 Activation 重复读写。卖方由此判断这相当于给现有 NVIDIA Hopper 系列"续命一代"，打破了"模型规模与硬件需求同步膨胀"的线性关系。

⚠️ **重要更正**：本次检索未在已取回材料中发现 MoE、MLA、FP8、GRPO、蒸馏小模型这些具名技术路线在 DeepSeek 语境下的原文出处。能核实的只有"每 token 激活约 8B/16B"（稀疏激活，但原文未用"MoE"一词）和"带有自我反馈机制的强化学习"一句话（无法确认是否 GRPO 或纯 RL）。若在别处看到"DeepSeek 用 MoE/MLA/GRPO 影响行业"，那不是本资料库能支撑的。

### 3. 竞争格局是分层共存，不是替代
卖方判断 1017 与 Kimi K3、小米 MiMo-V2.6 Pro 同处"开放权重第一梯队"，但"这次更新并未使开放权重前沿更接近领先的专有模型"；预计领先开放权重模型将**再次落后顶尖闭源约 6–12 个月**。分工上：低成本开放权重承接大批量、定义明确的智能体任务，对 GPT-6.1 Sol 级定价构成下行压力；复杂工程研发、知识型工作和高可靠企业任务仍主要依赖 Opus 5.5 等前沿模型。商业含义是闭源溢价向复杂推理与长尾任务收缩，企业级 token 收入与定价能力承压，**中间服务层（API/云模型服务）毛利率受压**——更多推理负载转向本地 GPU，收入向硬件与数据平台迁移。

### 4. 算力需求是"效率上升 + 总量上升"两面
单任务算力确实在降（KV Cache 压缩、激活参数小），但卖方同时判断"任务总量和 API 调用量的增加足以抵消单任务算力消耗的下降"，推理算力需求持续增长。资本开支侧仍在加速：Alphabet 2026 年第三季度资本开支 514 亿美元（去年同期约 240 亿），全年指引 1950–2050 亿美元。台积电管理层在 2026-10-15 业绩电话会上把"智能体 AI 推升算力需求"与"开源模型降低采用门槛"并列陈述。**所以"DeepSeek 让算力需求崩塌"的叙事，在已取回材料中找不到支撑**；"效率提升→旧卡延寿"与"总量增长"是不同层次，不构成矛盾。

### 5. 开源生态：更开放，但追赶更难
MIT 权重 + 第一梯队地位扩大了可用面：腾讯 CodeBuddy / WorkBuddy 已完成对 1017 的适配。但反向力量也在增强：闭源厂商主动收紧蒸馏可得性（API 不再返回原始思维链、thinking blocks 受限），卖方渠道调研称**同等规模蒸馏实验的成本已是 2026 年上半年的 10–50 倍**。这意味着"靠蒸馏追赶"这条路正在变贵，权重开源开发者必须在自主研发和训练算力上投入更多——开源生态的**进入门槛降低、追赶门槛升高，两者同时发生**。

### 6. 企业采用：用量升、支出增速降
微软渠道访谈显示生产环境采用仍有限，且"更严格的 ROI 要求、更便宜的模型路由以及自托管正在放缓支出增长，即使生产环境的应用范围仍在扩大"。**注意这是渠道样本口径，不是市场总量数据。**
