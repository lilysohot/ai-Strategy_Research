# clean-7 边界修正与复核（2026-10-21）

已修正上一轮发现的“邮编触发证券代码保护，评级表只删除表头”的问题。18 份开发资料差异复核通过，可以进入隔离库版本化重建和真实混合检索对照阶段。本轮完成代码、测试及构建前验证，未重建发布或更新向量。

## 修改内容

原项目 `plugins/corpus/preparation/clean.py` 的 `CLEAN_REV` 升至 `clean-7`：

1. 仅把明确标注为“邮编/邮政编码”的六位数排除在证券代码保护信号之外。同一单元若另有证券代码、持股事实或货币金额，仍受保护；保真文本不改写。
2. 免责节内连续同表的行整体判定，不在表头的句号处提前结算。表中含数字事实时，表头与数据行一起保留；没有事实的评级模板整体排除。原有读取状态、其他噪声规则仍优先，不把原有 noise/review 单元升级为正文。
3. 表格进入/退出、表身份改变及明确联系方式字段起始处结算前段，避免评级行与后面的邮编/联系方式共享保护信号。普通段落中的跨单元事实句继续整体保留。
4. 表分组保留页、表号与 DOCX 父路径；DOCX 行号不再误作表身份。跨页不推断续表。

未扩大免责标题词表，未增加 OCR、模型清洗或主 agent 逻辑；标题与正文合并的法律单元继续留作已知残留。
