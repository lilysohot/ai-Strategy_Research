## 主题小结

**1. 技术路线影响**（证据强度：中，全部来自卖方转述/推演，非 DeepSeek 一手技术报告）
- 资料库把 V4.1 Flash 的技术叙事定位在**"以架构与推理系统优化换取单位 GPU 产出"**，而非扩大参数规模：CED 把 40 层 Transformer 拆成 20 层 Encoder + 20 层 Decoder（长 Prompt 不必过完 20 层 Decoder，降低 Prefill）；CSA2 以 Full/Reindex/Reuse 三类层复用 Global KV 与 Top-K；叠加 FP4 Main KV 与 SWA Bounded Replay 后 Global KV Cache 降至约 1/4、Persistent KV Cache 降至约 1/8；Single-Pass mHC 用 Kernel Fusion 降 Activation 读写（E3）。
- **稀疏激活是可核实的**：Prefill/Decode 每 Token 分别仅激活约 8B / 16B 参数（E4）——但原文未使用"MoE"一词，也未说明总参数量，故"MoE 稀疏架构"只能记为【推断】而非【资料库直接记载】。
- **长上下文**是明确主题（E3 明写"长上下文推理"），但无上下文长度数值。
- **RL**：仅有一句"带有自我反馈机制的强化学习"（E6），无 GRPO、无纯 RL、无蒸馏小模型产品线的记载。**FP8/低精度**：仅见 FP4 KV cache（推理侧 KV 量化），未见训练精度记载，两者不可等同。
- **"被其他团队复现/采纳"**：本次检索**未找到**任何关于 MoE/MLA/FP8/GRPO 被其他团队复现或采纳的直接记载。可间接佐证的只有：开源权重使第三方自行托管并降价至 0.10/0.50 美元（E11）、以及开源权重模型整体能力趋同（E11）。这属【推断】，不足以支撑"技术路线被广泛采纳"。

**2. 开源生态**（证据强度：中偏强，但独立来源单一）
- MIT 许可证在 2026-10-19 与 2026-10-26 两份稿中一致记载（E1、E2）。
- 竞争格局：1017 与 Kimi K3、小米 MiMo-V2.6 Pro 同列"开放权重第一梯队"，但"并未使开放权重前沿更接近领先的专有模型"（E10）；预期开源权重落后闭源前沿 **6–12 个月**（E9）。
- 价格机制：开源权重 → 第三方自托管 → 服务商报价低于官方费率 → 成本成为最主要差异化因素（E11）；同时闭源入门级模型降价已"挤压"开源权重在短提示词场景的价格优势（同段，见 E8 chunk 内文）。
- 企业采用：微软渠道抽样显示开源模型仅占 Azure 模型消耗约 4%–5%（某合作伙伴口径；另两家口径为 <10% 与 20%–25%），主要障碍是安全性、模型来源可追溯性与声誉风险（E16、E17）。
