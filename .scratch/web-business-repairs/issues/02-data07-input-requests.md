## 交付结果

- 新增持久补数请求和追加式回答历史，支持 `pending/answered/cancelled/expired`、部分回答、歧义保留、到期处理和所有者隔离。
- 请求可来源于 Run 或尚未创建 Run 的事件；来源 Run 以 `input_required` 结束，待派发记录同步废弃。
- 完整明确回答在一个事务内保存业务版本、冻结新快照、创建且仅创建一个后续 Run、用户消息和 outbox；原 Run 快照不改。
- 回答携带资料预期版本；并发改版返回冲突。详情同时返回请求时版本和当前版本，页面要求用户明确勾选后才沿用当前版本。
- 新增 B 阶段通知基础：持久事件、用户游标查询、SSE、单条/批量已读；补数创建和回答事件与业务写入同事务提交。
- 补数中心改接真实 API，支持状态筛选、回答历史、刷新恢复、幂等重试和后续 Run 导航；通知中心改读服务端事件。
