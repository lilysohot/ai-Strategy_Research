# 09 — 统一 Claim 入口与证据链读取

Status: completed
Type: task

## 范围

- 默认 service / CLI 从源文件抽取 EvidenceRun，只写 corpus_evidence_runs。
- 新查询必须指定 run_id，返回来源版本、处理范围、完成状态、分页与用途许可。
- 比较/计算遵守 usable_for，旧校验版本不得自动获得新版计算许可。
- v1/v2 保留显式兼容入口与历史数据；不删表、不全库重抽、不混合新旧查询。
- 小范围验证正式入口的保存、查询、取证与计算；迁移期不继续扩展旧规则。

## 验收

- 新默认入口不触碰旧表；旧批处理必须显式选择。
- 缺版本、错版本、过期校验、仅可引用、未知覆盖和分页均有测试。
- 旧路径回归通过；真实小样本经过同一正式接口可复算。

## 结果

- 默认入口切换完成，兼容方法与 CLI 显式标记；未删除源文件、旧表或历史记录。
- 29 项新接口用例，语料专项共 197 项；真实小样本 57 字段、468 条事实取证、7 公式通过。
- 宏观已验收版本 2 个目标通过正式入口读回，仍不能比较/计算；本次未重新调用抽取模型。
- 说明与限制见 [正式入口验收](../claims-entry-report.md) 和
  [接口迁移指南](../../../docs/corpus-claims-interface.md)。
