# A1 分析层只读关联与归属

Status: ready-for-agent
Execution: not-started
Requirements: PR-DATA-07, PR-DATA-08, PR-DATA-12, PR-OUT-06
Depends on: R3 / 21, D1 / 22; D2 / 23 when calculation is needed

## 交付与验收

- 分开读取材料主张/论证和数据观测/计算，按研究问题选择关联，不能物理或语义混成原始事实。
- 数值比较核对标的、指标、单位、期间和用途所需时点；不可比保留双方及原因。
- 观点比较先核对表达者、对象、目标期间与假设，避免把假设不同或作者更新误当直接矛盾。
- 数据与材料冲突不得覆盖作者当时论据，不直接裁定作者错误；引用/转载去重，不冒充独立来源。
- 作者原话、作者明确视角、系统归纳视角和系统推断分别标记，综合结论可回取双方证据。
