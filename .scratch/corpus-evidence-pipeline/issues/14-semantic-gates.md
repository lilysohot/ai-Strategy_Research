# 14 完整事实绑定与覆盖修复

Status: ready-for-agent

Priority: P0

依据：[扩大留出失败报告](../expanded-holdout-report.md)。本轮只登记，不自动扩大修复范围。

## 第一阶段：阻止错误计算

- 指标、数值、单位、期间和预测/实际必须绑定同一原文事实；存在于同包不同位置不足以放行。
- 模型不能覆盖可信时间；known_at 无来源或早于实际公开时点不得用于计算/回测。
- 身份涵盖状态、口径和版本；计算入口遇到重复 ID 先拒绝，不允许字典静默覆盖。
- 五个现有合成反例全部拒绝，合法正控仍通过；新增未参与修复的反例验收。
- 升级校验版本，旧运行引用不改写，计算资格须按当前规则重新核验。

## 第二阶段：恢复正确召回

- 侧栏/联系信息不得造成整包实质正文被噪声规则吞掉；complete 不替代覆盖状态。
- 支持非年份列头的客户表，保持主体、2025 年、行列、单位、脚注和可回取坐标。
- 受控指标与单位规范化不靠放宽任意别名；NFP 岗位、同比百分比、修订合计必须区分。
- 本轮 12 单元格和 3 正文目标转为回归集；另外冻结新的留出资料检验泛化。

两个阶段通过仍不自动开放宏观公式，继续满足宏观契约的官方版本、预期快照和时间证明。
