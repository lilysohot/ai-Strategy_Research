## 范围与接口

### 最新决策：材料论据与数据推导分工（替代此前研报宏观计算主线）

2026-09-13 用户明确要求先跳过 M2 官方网页下载/验收，不再对研报宏观数字默认逐条回查官网。
用户随后明确：政府统计和股票行情等数据由其同花顺接口提供，材料用于观点、论据和视角。
既有市场工具保留，新政府数据契约与权限需确认；本次未授权购买或接入新端点。
这是需求范围调整，不是 403 已修复或 M2 真实验收通过。已有代码、测试和失败记录保留，不继续重试 BLS。

材料主线为：原文语境 → 观点/论据/视角及事实、行为归属 → 忠实理解和查询 → 小样本验收。
数据主线为：同花顺结构化观测 → 口径/期间/时点校验 → 数据计算；两者在分析层按需关联，不混为原始输入。
材料中数字仍保留为作者论据，既有财务复算保留为来源内部核对，不自动晋升为数据层观测。
输出必须说明来源和核验范围；未经外部核验的研报数据不得标成“官方已核验”。
来源中没有的首次/修订版本、精确发布时间、预期供应商等信息保留未知，不为填满字段而推测。
未知精确发布时点不阻断普通材料理解，但不能据此声称适用于发布事件回测。

下述首发事件差值及严格时间要求保留为可选的事件研究目标，不再作为所有 Corpus 宏观数据的默认准入条件。
实现仍使用统一模型、入口及计算逻辑，按用途声明所需证据，不另建第二套 claims 或绕过既有门禁。
本次仅更新文档；未改变运行时许可，不再计划把研报数字自动接成宏观数据计算主线。

唯一首期指标：`US.NFP_CHANGE_SA`；唯一首期公式：`nfp_surprise_delta_v1`。
原严格目标是基于已核验的首发实际值和发布前指定一致预期，产生可重放的有符号岗位差值。
该公式仅保留为可选严格用途，是否实现依 D1 数据可得性和 D2 范围决定；其首发/事前快照含义不降低。
不做所有宏观指标、不做 OCR、不迁移全库、不新增第二套 claims 存储或旧路径规则。

规划两个内部 seam，而不是复制整个管道：

- 来源核验 seam：官方发布与预期供应商各有不同 adapter；产出同一个不可变已核验输入。
- 纯计算 seam：接收已核验输入与 decision_as_of，只返回计算结果或结构化拒绝，不查询网络、不读取“最新值”。

解析、证据回取、run 身份、审计仍复用现有 corpus 统一入口。LLM 只能提出候选，不能产生可信审批记录。

## 每项必须包含的检查

### M1：模型与证据身份

- 年份/月份、release_at/known_at/ingested_at 分开；时间带偏移，禁止只有日期却假装精确到时点。
- actual/consensus、首发/修订、岗位数/同比率分别编码，不能把状态藏在自由文本指标名里。
- 明确受信任审核记录的写入方、版本与来源证据，禁止接收模型提供的 verified=true。
- 相同证据原子不同 kind/qualifier/vintage 有不同身份；相同 ID 的重复或冲突输入拒绝，不静默覆盖。
- 兼容旧 run 引用；不把新增默认字段写回旧内容哈希。

### M2/M3：仅在启用外部数据用途时检查可得性

- M2 输入指定档期与官方归档位置；保留原响应、内容 hash、发布时间证据，限制下载范围。
- M3 首选单一已授权供应商的已归档快照。没有账号/权限时可用用户合法提供的快照做人工核验导入。
- 需要用户确认的唯一业务选择：哪家预期供应商、何种统计方式，以及是否有可合法使用的历史快照。
- 不自动购买订阅、安装交易插件、登录新账户、发送邮件或抓取未经授权的付费资料。
- 无法取得历史预期快照时记录 `consensus_snapshot_missing`；不从事后报告反推一个快照。
- 第三方接口并非自动可信：保留供应商、原始响应/数值单位、期间和其提供的版本/时间字段。
  只有最新修订值的接口可以服务相应用途，但不能冒充历史首发快照。不要求常规数据逐条再爬官网。

### M4：计算门禁

- 原 M4 后续归 D2/A1；以下精确时间与首次发布门禁仅适用于严格事件用途，不套用于所有引用。
- 普通研报推导仍要核对完整事实、数值单位、统计月份和角色；无法确定可比性时不强算。
- 先验证记录身份、版本与证据，再检查配对维度和时序，最后做 Decimal 算术。
- `survey_cutoff <= snapshot_known_at < release_at <= decision_as_of`；实际值可知时间与材料可知时间同样核验。
- 当前 financial `known_at` 是文档发布日期候选，不能直接迁入宏观 verified 输入。
- 对失败输出稳定 reason_codes 和 null 值，不返回 0；拒绝结果同样绑定输入 ID 与契约版本。
- 对完整 M01—M16 测试夹具先验证红/绿能力；数值正常用例至少覆盖正、负、零预期和倍率转换。

### M5：冻结测试边界

- 当前优先真实研报的小范围可用性测试；以下官方事件与历史快照留出是可选严格用途的后续验收。
- 建议开发回归集 3 个事件，另留出 3 个未参与规则调整的事件；数据可得性不足时明确缩小，不虚构样本。
- 按已授权资料选事件后，先冻结官方实际值/供应商预期、版本、时间证据和预期拒绝项，再运行。
- 至少覆盖首发事件、后来发生修订的事件，以及预期快照缺失负控。
- 分开报告字段忠实度、计算正确率、错误放行率、任务完成率及不可核验比例；不混成一个总准确率。
- 不能把开发回归通过当成独立留出通过；每个事件只按预先预算执行，失败不为刷分重复调用。

### M6：上线与回滚

- 只有 M5 的必要输入与错误放行门槛通过，才讨论启用；本轮没有启用授权。
- 开启范围限定指标、供应商、公式版本；不启用 surprise 百分比、z-score 或修订分解公式。
- 回滚仅撤销计算许可或关闭开关，保留原文、历史 run、审核记录与计算结果。
- 接入测试必须从现有统一入口完成写入、查询、取证与重放；不新增 claims_v3 或另一套默认读取路径。

## 环境影响

已观察到的是当前环境请求指定 BLS 网页返回 403，不足以认定所有网站或第三方 API 均不可访问。
本地研报读取、抽取、校验、推导实现与离线测试不依赖该网页，因此不受此失败直接阻断。
未来接口能否接通取决于所选服务的网络、凭证、权限、限流和历史数据覆盖，选定后单独小范围验证。
