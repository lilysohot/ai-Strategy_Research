## 本轮问题

上一轮移除外围工具后，4 个可观察的 B 响应仍继续搜索，因此外围工具不是续搜的必要前提。现在检验一个更窄的问题：**四个显式遍历进度字段，是否促使模型把文档尚未读完当作用户任务尚未完成？**

## 两组输入与唯一差异

A 使用上一轮 TOOLSET A 的完整请求，保留 15 个工具；B 只从最后一条文档回执 JSON 中删除以下四个字段：

```json
{
  "total_units": 272,
  "position": {"unit_index": 5, "offset": 0},
  "exhausted": false,
  "fetch_complete": false
}
```

B 不把 false 改成 true，也不添加“证据充分”“请停止”“现在回答”等文字。结果正文由 2,603 字符降为 2,494 字符，相差 109 字符。

两组均保持：原始用户问题、已有 fetch 调用及 ID、全部 5 个原文单元、所有引用、真实 original_names、文档身份、scope=document、coverage_scope、source_coverage=unknown、next_cursor、retry_cursor、原始 hint、15 个工具及所有描述/schema。

因此 B 仍可搜索、补读、续页、列目录、提交清单与报告；不是靠禁止操作迫使作答。原始 hint 仍提到续读与 fetch_complete 的含义，游标也仍表明有可继续读取的内容。

**这轮只测试四个显式进度值，不测试全部分页线索。** B 若仍续搜，只能排除这四个字段是必要前提，不能排除游标、hint 或整套文档阅读语义的影响。四个字段是一个组合，不能据结果单独指认某一个字段。

## 评分：保留执行质量约束
