# 整页方向判断与校正：已知回归通过

**已实现隔离版整页定向模块，18/18 个回归案例符合预期。** 其中 15 个识别案例正确转正，177 次固定文字/数字检查全部匹配；3 个拒绝判断对照均返回 unknown。没有更换模型，未接入正式读取或入库，四张真实页的人工复核记录仍为 pending。

这解决了当前已知的 DDOG 短数字误旋转和 PLTR 倒置页数值错误，但不是未见样本准确率、全文完整性、表格结构或线上验收结论。

## 实现方式

新增 [page_orientation.py](page_orientation.py)，接口为 `orient_image(rgb, engine)`，只接收图像和原 RapidOCR small 引擎。文件名、预期文字、评分检查项和测试旋转角度都只属于回归脚本，不进入定向模块。

1. 原检测器给出文字框，以细长框的多数方向确定横/竖轴。
2. 在两个相反方向运行识别；关闭逐行方向分类，避免它再次翻转短数字。
3. 至少三个含文字的行、分布在至少两个纵向区域，且最佳方向的文字证据充分领先，才接受整页方向。纯数字不参与方向投票，单个标题不够定向。
4. 证据不足或冲突时返回 unknown，不生成权威校正结果；保留输入及候选供人工检查。
5. 确认方向后返回校正方向的文字，并把框映射回输入图。方向决定仍带 `needs_review=true`，不会自动批准全文或财务数字。

阈值在首次真实推理前冻结，整批没有调参或按错误数字挑选方向。权重差和识别分数用于候选比较，不是校准后的正确概率。具体参数、文件哈希见 [evidence.json](evidence.json) 与运行 manifest。

## 回归结果

沿用前批固定输入和助手转写的检查项，不重新挑选容易通过的数值。测试先对图像施加顺时针旋转，再交给模块；真实期望角度仅用于事后评分。

| 样本 | 正向 0° | 输入 90°，模块校正 270° | 输入 180°，模块校正 180° |
| --- | ---: | ---: | ---: |
| DDOG 第 7 页 | 19/19 | 19/19 | 19/19 |
| SaaS 第 16 页 | 10/10 | 10/10 | 10/10 |
| PLTR 第 9 页 | 16/16 | 16/16 | 16/16 |
| Copilot 第 2 页 | 8/8 | 8/8 | 8/8 |
| 合成正负号/单位页 | 6/6 | 6/6 | 6/6 |

真实四页共 159 次检查，合成符号页 18 次，共 177/177。每页三个方向均给出正确角度；正向页面保持 0°，没有新增误旋转。数字单元格与合成整行精确比较，部分正文/单位片段按冻结区域子串比较；这些只是固定检查，不是全文真值。

已知失败的改善：

- DDOG 原路径的 `7.3% → 73%`、`8.5% → 85%`、`11.9% → 1.9%`、`6.3% → 63%` 本轮均未再出现。
- PLTR 倒置页两种旧候选均错的 `990.0 → 0.066`、`17.5% → 1725%`，现在先校正整页，输出分别恢复为 `990.0`、`17.5%`。
- 第二批全局关闭单行分类时，180° 真实项只有 4/34；本次增加整页定向后，同一组 180° 检查为 34/34。

另有三个合成拒绝判断案例：空白、纯数字、上下方向均衡混排。它们均返回 unknown，校正角度为 null，不把“没有可靠答案”伪装成成功定向。这里的 3/3 表示拒绝行为符合要求，不表示这些页面内容被正确读取。

## 隔离、成本和检查

实际运行容器的镜像 ID、断网、只读根目录、2 CPU / 4 GiB 已通过只读 Docker inspect 记录在本地 runtime.json。镜像仍是 `sha256:141ee6ffbc6d0ec0c025f9deccbf93ae832f6721ef90018de93312b6dfc36c1b`，模型配置/权重不变。

18 个新进程合计 **343.584 秒**，最大采样进程树峰值 **844.4 MiB**。单页包含导入、渲染、检测及两个方向的识别，低证据页可能提前退出；相比单遍 OCR 增加了计算量，不能当成线上延迟承诺。每页 90 秒超时，本次无超时。

- 输入副本、冻结检查项及 83 个读取器/算法相关文件哈希检查通过；本批没有修改既有读取器、模型配置或前批输出。
- 5 项针对性单元检查、Ruff E9/F、diff 检查通过；545 文件符号检查零缺失，framework 447/447、eval 496/496 导入、仓库 preflight 通过。
- 对照页 106 个链接检查通过；15 个校正预览与源页逐像素一致，3 个 unknown 案例没有校正预览；HTML 和图片 HTTP 访问成功。

这些是隔离实现的工程检查，不是线上沙箱验收。源码和摘要归档，原 PDF、图片、完整 OCR 及方向锚点全文仅保留本地产物；Git 摘要只保留锚点索引、数值证据和冻结检查结果。
