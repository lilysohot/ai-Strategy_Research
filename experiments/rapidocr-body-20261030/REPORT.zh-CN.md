# RapidOCR small 正文读取复测：26 页回归＋4 页补充

2026-10-30。建议保留这条本地方案，作为按需 OCR 的候选组件继续推进；目前足够支持隔离验证，尚不能把输出当作无需复核的完整研报正文。全部代码留在实验目录，默认关闭，未接入生产。

## 本轮变化与结果

新增独立 `body_reader.py`，包含原生正文质量门槛、自动分栏顺序和异常证据。没有更换 small 模型，也没有调用视觉大模型。原生正文通过门槛时原样返回；文字层缺失或质量不足时才 OCR。

原来的 26 页包含 23 页正文评价、3 页表格/资料控制页。固定参考共 3341 个非空白字符、127 项关键内容，保持上轮比较口径：按片段最佳匹配计算编辑距离，仅忽略空白，保留标点和大小写。

| 原 26 页指标 | 上轮全部使用原始 OCR | 本轮原生优先＋自动分栏 |
|---|---:|---:|
| 固定片段编辑错误 | 233 / 3341 | 4 / 3341 |
| 片段加权错误率 | 6.97% | 0.12% |
| 中文片段错误率 | 0.73% | 0.17% |
| 英文片段错误率 | 17.56% | 0.08% |
| 关键内容严格命中 | 124 / 127 | 126 / 127 |
| 26 页处理总耗时 | 288.63 秒 | 173.28 秒 |
| 单页耗时中位数 / P95 | 10.10 / 18.80 秒 | 8.66 / 17.50 秒 |
| 采样进程树 RSS 峰值 | 782.1 MiB | 811.5 MiB |

本轮 11 页保留原生正文、15 页执行 OCR。11 页返回文字与读取到的原生文字完全一致；两页仅能提取数字而缺失中文正文的异常文字层均触发 OCR。15 页重新推理的原始 OCR 文字与上轮逐页一致，说明本轮改善来自路由和阅读顺序，而非随机获得了更好的识别。

为了区分两项改善，另对旧 OCR 做了独立缓存重排诊断：233 处错误降到 15 处；加上原生优先后，实际复测剩 4 处。缓存重排仅用于分析，没有把它的耗时作为推理耗时。自动分栏在缓存中识别了 4 页主栏＋侧栏，在实际 OCR 路径中识别了其中 2 页；另外 2 页直接保留原生正文。

15 页 OCR 的耗时中位数为 9.94 秒、P95 为 19.46 秒；11 页原生读取中位数为 0.265 秒。总耗时下降主要因为跳过了 11 次 OCR。本轮只测串行冷启动，不能推断并发吞吐量。

## 仍未解决的错误

30 页均执行完成，其中 7 页返回 `needs_review`，其余 23 页为 `ok`。复核提示也包含页眉、表格或页脚，不能解读为 7 页正文均有错误；`ok` 也不保证全文正确。

| 既有问题 | 本轮行为 | 是否已恢复原文 |
|---|---|---|
| d054 第 1 页英文正文曾被 OCR 识别为碎片 | 原生优先，保留真实原句 | 是，来自原生文本 |
| d068 第 3 页英文正文一行乱码 | 标记低置信度、碎片词、数字异常，保留坐标及原 OCR | 否 |
| d066 第 1 页 `6.4TOPS/W@INT8` 多识别一个 W | 即使置信度约 0.99，也标记重复单位 | 否 |

因此固定片段 0.12% 不能解读为全文准确率 99.88%。乱码行位于固定片段之外，依然实际存在；单位错误则是未命中的那一项关键内容。没有自动纠错，也没有局部二次 OCR。本轮完成的是发现问题并保留证据。

## 隔离和失败行为

11 项接口测试通过，覆盖默认关闭、保留完整原生文字、坏文字层路由、OCR 错误/超时/空结果回退、异常坐标保留原始 OCR、分栏不丢行、跨栏标题分区、异常标记不改写以及页码检查。

实际控制测试中，空白页返回 `empty`，损坏 PDF 返回 `error`；适配器超时保留已有原生文字并标记，整页超时由实验进程组终止。完成后无残留 worker，容器已退出。

现有读取器对 26 页的 auto/text/image 共 78 项输出前后完全相同。780 个已有文件及 Git 状态未改变；68 份原始 PDF 哈希未改变，实验副本也未改变。生产依赖、缓存和配置没有写入。比较环境缺少 Poppler，所以这 78 项只能证明当前 pypdf 回退路径未受影响，不能替代生产 Poppler 环境的集成回归。

## 接入判断

这轮证据支持“完整原生正文优先，缺失正文再运行本地 small OCR，异常带证据返回”。本轮使用 2 CPU 配额、4 GiB 内存、无 GPU，在这个配置下串行跑通；没有测试更低配，811.5 MiB 的进程树峰值不能当成最低系统内存。推理离线且无按页 API 费用。

模块不解析图片语义，也没有恢复图表结构，但为避免误删正文，仍保留 OCR 已检测到的所有文字行。主栏、侧栏和图表标签并没有被可靠分类。对只有标题的页面可能多跑 OCR，对含足够文字但局部缺失的原生层也可能漏触发；异常规则的精确率和召回率尚未建立。

当前交付保持实验隔离。正式接入前，还需要实际 Poppler 路径回归、更多未见双栏/混合版式和原生层局部残缺样本，以及下游对 `needs_review` 的明确处理。无需因为这一轮结果马上引入付费视觉模型。
